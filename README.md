# Little Lemon Food Ordering App

A React Native mobile application built using Expo for the Meta React Native Capstone Project.

## Features

- Splash Screen
- Onboarding Flow
- Persistent User Storage
- Home Screen
- Hero Section
- Search Functionality
- Category Filtering
- Food Menu List
- Profile Screen
- Editable User Information
- Logout Functionality
- Stack Navigation

## Technologies Used

- React Native
- Expo
- React Navigation
- AsyncStorage

## Installation

```bash
npm install
npx expo start
```
